# atliq-bi-dashboard-powerbi
Power BI business intelligence dashboard for AtliQ Hardware with Finance, Sales, Marketing, and Supply Chain views. Tracks net sales, gross margin %, market share vs target, and forecast accuracy using Power Query, DAX, and a relational data model.

# 📊 AtliQ Hardware – End-to-End Business Intelligence Dashboard (Power BI)

## 🏢 Business Context
AtliQ Hardware needed a centralized, data-driven view of performance across
Finance, Sales, Marketing, and Supply Chain, replacing manual Excel-based
reporting with an interactive Power BI solution.

## 🎯 Objectives
- Create a single source of truth for business reporting
- Identify profitability drivers (net sales, GM%, cost structure)
- Monitor market, channel, and target performance
- Track forecast accuracy for supply chain planning

## 🛠️ Tech Stack
Power BI · Power Query · DAX · Data Modeling · SQL · Excel

## 📈 Dashboard Pages
| Page | Purpose |
|---|---|
| Home | Navigation and report overview |
| P&L Check | Validation of profit & loss figures |
| Finance View | Net sales, COGS, gross margin %, profitability trends |
| Sales View | Channel, customer, and product performance |
| Marketing View | Market share and target tracking |
| Supply Chain View | Forecast accuracy, absolute and net error |
